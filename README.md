# Windows Go for the ESP32
A windowing OS for the ESP32 with real time desktop streaming to your browser

YOu can flash the all in one bin from this repository to any ESp32 (prefer VROOM 1 module) - 

YouTube Video: https://www.youtube.com/watch?v=i1Q2DKtjzAk

Requirements:
-------------
Board: Must have at least 4MB Flash
Network: rename your Phone hotspot to ssid: Mooo with PW: MooMoo1234!  (hard coded in the bin)
Browser CLient: Must use the Windows GO html viewer from this repository

*Getting the IP of your Board: See console output from board with IP or look at your cell phone hotspot will have the IP listed as connected device
