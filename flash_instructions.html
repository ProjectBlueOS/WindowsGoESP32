WindowsGo — Welcome v1

What is WindowsGo?

WindowsGo is a tiny computer-in-a-board. It turns a small ESP32 microcontroller into a full desktop experience — a classic Windows 95-style environment with a start menu, desktop icons, a live clock and apps that really work.

There's no screen on the board itself. Instead, the ESP32 broadcasts its own private WiFi hotspot-like connection and streams the entire desktop straight to your web browser. Open a page on your phone or laptop, and a retro desktop appears instantly — like a little computer living inside your browser. Everything runs on the board; your browser is just the window into it.

It's fast, it's fun, it's a tiny slice of computing history you can hold in your hand — and you can have it running in about five minutes.

What you need

  • An ESP32 development board (the classic ESP32-WROOM-32 style)
  • A USB cable that can carry data (not a charge-only cable)
  • A computer with esptool installed (see Step 1)
  • A web browser (Chrome recommended)

Step 1 — Install the flashing tool

Download and install esptool from the official Espressif esptool page.

Step 2 — Connect your ESP32

  1. Plug the ESP32 into your computer with the USB cable.
  2. If the board has a driver, let it install automatically.
  3. Find out which port it uses:
    • Windows: check Device Manager → Ports — it shows as COM3, COM4, etc.
    • macOS / Linux: it usually appears as /dev/ttyUSB0 or /dev/cu.usbserial-XXXX.

Step 3 — Flash the board

Keep the esp32_WindowsGo_V1.bin file in the same folder as your terminal is open, then run this single command (replace COM3 with your port): 

esptool --chip esp32 write-flash 0x0 esp32_WindowsGo_V1.bin
Copy

One file does everything — there is nothing else to flash. You'll see a progress bar, then "Hard resetting", which means it's done.

Trouble flashing? Erase first. If the board has been used before and won't accept the write, erase it first: 
esptool --chip esp32 erase_flash
Then run the flash command above again.

Step 4 — Connect and enjoy

  1. Power the ESP32 from any USB port.
  2. It connects to the configured WiFi network. The board is set to connect to the Mooo network — the password is MooMoo1234!. Make sure that network is reachable.
  3. Open a browser on any device on the same network and go to the board's IP (see below).
  4. The desktop appears. Click around — the clock runs live, the apps respond, it's a working little PC.

How to find the IP address

Right after the board powers up it prints its address to the serial console, then repeats it whenever it (re)connects. To read it:

  1. Keep the ESP32 plugged into your computer over USB.
  2. Open a serial monitor set to the board's COM port at 115200 baud.
    • esptool doesn't have a monitor — use any free serial terminal (e.g. Arduino IDE Serial Monitor, PuTTY, or screen /dev/ttyUSB0 115200 on macOS/Linux).
  3. Watch the log. The board prints a line like got ip: 192.168.1.42 (the numbers will differ for your network).
  4. In the Winddows GO IP box, type 192.168.1.42 — use the IP you saw.
Tip The IP can change when the board reconnects or the router restarts. Just read the printed line again and use the new address. The browser address bar keeps the last one you visited, which makes it easy to reconnect.
Notes
  • One browser connection at a time — closing the tab and reopening connects again.
  • Use Chrome for the best experience.
  • If the screen seems blank, refresh the page.
  • Keep the board powered from a stable USB supply.
